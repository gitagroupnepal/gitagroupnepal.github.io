GITA AAROGYAM & AROMA — WEBSITE + ANDROID-READY APP

This package is a responsive website and installable Progressive Web App (PWA).

FEATURES
- Gita Aarogyam and Aroma Herbal Gharelu Udhog branding
- Made in Nepal / Pure Natural Healthy Life
- Hindi + English toggle
- Six real branded product images from the supplied Word document
- Categories: Powders, Oils, Agarbatti & Dhoop
- Shopping cart saved on the device
- WhatsApp order button using 9814265015 (+977 country code)
- Contact details from the supplied document
- Android install support through Chrome "Install app" / "Add to Home screen"

HOW TO USE
1. Upload this whole folder to a web host.
2. Open index.html through the hosted HTTPS website.
3. On Android Chrome, choose Install app / Add to Home screen.

IMPORTANT
The Word document did not contain confirmed final selling prices. The displayed prices (Rs. 150, 130, 120, 100, 120, 450) are placeholders and should be replaced before launch.

For a Play Store APK/AAB, this PWA can be wrapped with Capacitor or another Android WebView wrapper after the final domain is chosen.
